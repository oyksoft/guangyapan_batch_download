# 光鸭云盘 - 获取直链

一个轻量级的油猴（Tampermonkey）脚本，为光鸭云盘网页版提供批量获取文件直链的功能。

## 功能特点

- **批量获取直链** - 一次选择多个文件，一键获取所有直链
- **智能识别选中文件** - 通过 React 组件状态获取选中文件，不受虚拟滚动影响
- **并发请求** - 支持并发获取直链，提高效率
- **失败重试** - 网络波动时自动重试（最多 3 次，指数退避）
- **取消功能** - 获取过程中可随时取消
- **复制方便** - 支持一键复制全部链接，或只复制选中的链接
- **路由适配** - 在特定路由（如 `#/transfer/cloud`）下不显示按钮

### 方式二：手动安装

1. 安装油猴扩展：[Tampermonkey](https://www.tampermonkey.net/)（Chrome、Firefox、Edge 等主流浏览器均支持）
2. 点击脚本文件 `guangyupan_get_links.user.js`，复制全部内容
3. 打开油猴扩展，点击左侧「+」号新建脚本
4. 粘贴代码并保存

## 使用方法

1. 打开光鸭云盘网页版：https://www.guangyapan.com
2. 进入文件所在目录，选中需要获取直链的文件
3. 点击「获取直链」按钮
4. 在弹窗中查看直链，支持复制全部或部分链接

## 工作原理

脚本通过遍历 React Fiber 树，读取 `FileList` 组件的 `props.dataSource` 和 `props.selectedItems` 来获取：

- 完整文件列表（用于建立 fileId 到文件名的映射）
- 当前选中的文件 ID 集合

这种方法可以正确处理虚拟滚动场景，即使文件列表只渲染了屏幕上可见的部分，也能获取所有选中文件的信息。

## 技术细节

| 项目 | 说明 |
|------|------|
| 文件 ID 格式 | 19 位数字字符串（如 `1895377741382598728`） |
| 文件类型判断 | `resType: 1` = 文件，`resType: 2` = 文件夹 |
| API 地址 | `https://api.guangyapan.com/nd.bizuserres.s/v1/get_res_download_url` |
| 并发数 | 3 |
| 请求超时 | 10 秒 |
| 重试策略 | 指数退避（500ms, 1s, 2s） |
